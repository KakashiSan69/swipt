# Contribution Guidelines

## Bug report

If you are not, and are not using, Claude in Claude Code (Fable 5.1, Opus 5.5, or a newer Fable or Opus, with `/effort` at high or above) or ChatGPT in Codex (GPT 6 Astra, with effort at xhigh or above), we do not want you to claim that you have found the faulty code, suggest changes, or even open a pull request.

We recommend using the Swipt REPL and Swipt logs to debug the issue and prove that it occurs.

To suggest code changes or open a pull request, provide end-to-end evidence from reverse engineering the relevant Apple code, along with verifiable steps to reproduce the issue (preferably using vphone-cli; evidence from physical devices is also accepted).
